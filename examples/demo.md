# Colored Markdown

Make the ==important part== stand out, ++underline++ a key term,
or write in {red}red{/red}, {blue}blue{/blue} and {green}green{/green}.

{bg:yellow}Yellow background{/bg} · {bg:blue}blue background{/bg} · {color:#ff8800}custom #ff8800{/color}

## Mix with normal Markdown

- {red}**Bold red**{/red} list item
- ==Highlighted *italic*== item
- [A {purple}colored{/purple} link](https://code.visualstudio.com)

| Syntax | Result |
|---|---|
| `==text==` | ==text== |
| `{red}text{/red}` | {red}text{/red} |
| `{bg:yellow}text{/bg}` | {bg:yellow}text{/bg} |
| `++text++` | ++text++ |
