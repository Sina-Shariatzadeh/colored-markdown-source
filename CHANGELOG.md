# Changelog

All notable changes to this extension are documented here.

## [1.0.0] - 2026-11-03

### Added
- `==text==` yellow highlight.
- `++text++` underline.
- `{red}text{/red}`, `{blue}text{/blue}` and 12 more named text colors.
- `{bg:yellow}text{/bg}` colored backgrounds.
- `{color:#hex}text{/color}` and `{bg:#hex}text{/bg}` custom colors.
- Live rendering in VS Code's built-in Markdown preview.
- Coloring of the syntax directly in the editor as you type.
- Commands and context menu to wrap selections, with shortcuts for highlight and underline.
